Links that survive the trip

Arabic URL encoder and decoder

Turn an Arabic link into a safe percent-encoded URL, or decode a copied link back into readable Arabic.

Result

encodeURI keeps URL structure intact (slashes, colons, question marks). Use it for a full link, not for a single query value.

Everything runs locally in your browser. Nothing is uploaded to a server.

URLs are limited to a small set of ASCII characters. Arabic letters, spaces, and many punctuation marks must be percent-encoded before they can travel safely through browsers, email clients, analytics tools, and server logs. A raw Arabic URL often works when pasted into a browser, then breaks in a chat app, a redirect, or an API request.

This tool encodes with encodeURI, which converts the Arabic characters while leaving the structure of the URL intact: https://, slashes, the question mark, and the separators between query parameters. It can also reverse the process and turn a percent-encoded link back into readable Arabic.

Encoding a full link

Paste a complete URL such as https://example.com/search?q=لوحة مفاتيح and choose Encode. The Arabic text becomes a sequence of %D9... triplets, while the scheme, host, path slashes, and query punctuation remain readable. That is the correct behavior for a full link.

If you need to encode a single value rather than a complete URL, use your programming language's encodeURIComponent instead. It also encodes slashes and question marks, which would break a full URL but is correct inside one query parameter. This page deliberately uses the full-URL variant so you can paste a link and get a working link back.

Decoding a copied link

Choose Decode to turn percent triplets back into characters. This is useful when a link arrives from a redirect, an email tracker, or a social app and you want to see the Arabic query before opening it. Decoding also reveals the destination path, which is a simple privacy check before you click.

If the input contains an invalid sequence, the tool reports an error instead of producing a half-decoded link. That usually means the link was truncated when it was copied.

Why Arabic needs encoding

Each Arabic letter is two bytes in UTF-8, and each byte becomes a percent triplet. A short Arabic phrase can turn into a long string. The length is normal; it is not a sign that the link is corrupted. Keep the encoded form when you store the URL in a database, a QR code, or an email template, and decode it only for display.

Spaces are another common failure. A raw space ends a URL in many parsers, so it must become %20. The Arabic comma and question mark have their own triplets. Encoding handles all of them consistently.

Canonical URLs and slugs

For a public page, a readable slug is better for users and for search engines. Percent-encoded Arabic in the path works, but it is hard to share and can be rewritten by different tools. Many Arabic sites use a transliterated Latin slug and keep the Arabic title in the page content. Use this encoder for query strings, tracking parameters, and links that must preserve an exact Arabic value, not as a substitute for a clean site structure.

Local conversion

Encoding and decoding happen in your browser. The link is not fetched, opened, or sent anywhere. That matters when the URL contains a private search term or an internal document path.

Check before sharing: decode a shortened or tracked link to see the real Arabic query. If it contains private text, remove it before forwarding the link.

Quick answers

Frequently asked questions

What does percent encoding do?

It replaces characters that are not allowed in a URL with a percent sign and two hexadecimal digits. Arabic letters become sequences such as %D9%84.

Does it encode the whole URL or just the Arabic part?

It uses encodeURI, so the URL structure stays intact (https, slashes, question mark) and the Arabic characters are encoded. Use encodeURIComponent in code if you need to encode a single query value.

Can I decode a link before opening it?

Yes. Choose Decode and paste the link. The tool shows the readable Arabic and the destination path without fetching the page.

Why is the encoded link so long?

Each Arabic letter uses two UTF-8 bytes, and each byte becomes three characters in percent form. The length is expected and does not mean the link is broken.

Is the link opened or sent anywhere?

No. Conversion is local JavaScript. The URL is not requested, logged, or shared by this site.
