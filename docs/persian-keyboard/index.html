Farsi and Persian typing

Persian keyboard for Farsi and Dari

Type Persian with the four extra letters, the correct yeh and kaf, and a Finglish converter that understands everyday words.

The on-screen keys follow the standard Persian layout used in Iran and Afghanistan.

Everything runs locally in your browser. Nothing is uploaded to a server.

Persian, also called Farsi, uses the Arabic script with four additional letters: پ for p, چ for ch, ژ for zh, and گ for g. It also uses the Persian ک and ی rather than the Arabic kaf and ya. A keyboard that lacks those distinctions produces text that looks almost right but reads as Arabic, not Persian.

This page provides a standard Persian layout, a Finglish converter, and a harakat row for the cases where diacritics are needed in teaching or poetry. Everything runs in the browser.

The four letters and the two lookalikes

The extra letters carry real meaning. پدر is father, not بدر. چای is tea, not جای. ژاله is dew or hail, not زاله. گل is flower, not کل.

The layout also places ی on the key where an Arabic keyboard has ي, and ک where it has ك. The two forms are visually similar but are different code points, and Persian search engines and fonts expect the Persian forms.

Type Finglish, get Persian script

Finglish is Persian written with Latin letters: salam, chetori, merci, khoda hafez. In Finglish mode, type the phrase and press Space. The converter maps ch to چ, zh to ژ, sh to ش, kh to خ, g to گ, and k to the Persian ک.

Common words and phrases are converted as units, so chetori becomes چطوری rather than a literal letter-by-letter guess. The converter is not a full transliteration standard; it is a practical tool for chat, notes, and captions. For formal writing, type directly in layout mode or correct the result afterward.

Typing on a physical keyboard

In layout mode, the physical keys follow the common Windows Persian layout: Q is ض, W is ص, A is ش, and the four Persian letters sit where Iranian users expect them. If your muscle memory comes from an Arabic keyboard, the main differences are ی on D, ک on the semicolon, and گ on the apostrophe.

Use Latin mode when you need to type a web address, an English name, or a number without conversion. The mode switch does not clear the editor.

Punctuation and numbers

Persian uses the Arabic comma ، and question mark ؟, plus the Persian Arabic-Indic digits ۰۱۲۳۴۵۶۷۸۹. The keyboard's extra row includes the punctuation marks; the numeral converter can change digits between Persian, Arabic-Indic, and Western forms if you paste a mixed document.

Copying and sharing

Press Copy, then paste into Telegram, WhatsApp, Word, or a subtitle editor. The output is Unicode and does not need this site to display. If a design app shows disconnected letters, use the Photoshop fixer on the text first.

Note: Persian and Arabic share a script but not an alphabet. Keep the Persian ک and ی in Persian text; replacing them with Arabic forms can break search and spell-check.

Quick answers

Frequently asked questions

What is the difference between a Persian and an Arabic keyboard?

A Persian keyboard includes پ, چ, ژ, and گ, and it uses the Persian forms of kaf and yeh (ک and ی). The physical key positions also differ from the Arabic 101 layout.

Can I type Finglish and convert it to Persian?

Yes. Choose Finglish mode, type a word such as chetori or salam, then press Space. The converter produces Persian script and recognizes several common words as whole units.

Are the Persian and Arabic digits different?

Persian uses ۰۱۲۳۴۵۶۷۸۹, while Arabic-Indic digits are ٠١٢٣٤٥٦٧٨٩. They look similar but use different code points. The numeral converter can switch between them and Western digits.

Does the keyboard support Dari?

Dari uses the same Persian script and the same four extra letters, so the layout works for Dari text as well. Regional vocabulary and spelling preferences may differ.

Is my text sent anywhere?

No. The keyboard and converter run entirely in your browser. Copying places the text on your clipboard; nothing is uploaded.
